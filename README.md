# GPTIPS2 Python Integration

This project sets up a Python server to interface with the **GPTIPS2** symbolic regression model implemented in MATLAB. The server receives input data and parameters, runs the GPTIPS2 model, and returns predictions.

## Overview

- **Purpose**: Enable integration between Python applications and the GPTIPS2 symbolic regression engine in MATLAB.
- **Components**:
  - Python server for handling HTTP requests and responses.
  - MATLAB backend running GPTIPS2 for model computation.
  - Communication layer between Python and MATLAB.
